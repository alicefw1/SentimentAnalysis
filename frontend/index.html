平台简介

情感智析云平台是一个统一的情感分析云平台，前后端解耦：后端提供 Flask/REST API 与批量、流式处理接口，前端提供实验室、对比、报告与可视化中心。

特性：多模型热插拔（缺模型文件自动回退 SnowNLP）、三分类预测、批量/实时管道、模型性能对比、历史记录与配置持久化。

“基于深度学习的细粒度情绪识别”

细粒度意味着不仅判断整段的情感极性，还关注句子/短语级别的情绪强度、语境依赖和主体指向。长文本会被分段分析、聚合；注意力与 BERT 编码捕捉上下文关键信息。

当前工作：清洗并拆分 ChnSentiCorp 等数据；训练 LSTM/BiLSTM/Attention/BiGRU/BERT 多套模型；提供 ONNX 导出脚本；实现 REST 推理接口与可视化前端。

模型简介
LSTM

轻量单向基线，适合低资源或边缘场景；训练快、依赖少，提供稳定的三分类能力。

BiLSTM + Attention

双向捕捉上下文，注意力聚焦关键情感片段，是默认推荐模型，在长评论与对比实验中表现均衡。

BiLSTM + Self-Attention

自注意力替代显式注意力头，提升长距离依赖建模能力，减轻人工特征工程需求。

BiGRU + Self-Attention

参数量更小但捕捉双向语义，与自注意力结合在速度与精度间取得平衡，适合中等规模推理。

BERT（中文）

基于 bert-base-chinese 微调，适合需要更高精度和上下文理解的场景，可导出 ONNX 以提升部署效率。
